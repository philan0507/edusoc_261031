# 교육사회학 강의 웹사이트 — 사용법과 배포 안내

서버 없이 브라우저에서 바로 열리는 정적 사이트입니다. `index.html`을 더블클릭하면 열립니다.

## 1. 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 뼈대 |
| `config.js` | **사이트의 모든 내용**(문구, 주차별 강의, 일정, FAQ, 교수자 등) |
| `styles.css` | 디자인(분홍·보라 색상은 맨 위 `:root`) |
| `app.js` | 화면 그리기(커리큘럼 아코디언, 달력, 슬라이드 등) |
| `participate.js` | 수강생 기능(투표, 회원 가입, 로그인·출석·과제 제출, 팝업, 폭죽) |
| `admin.js`, `sha256.js` | 관리자 모드와 비밀번호 해시 |
| `quiz.js` | 라이브 퀴즈(교수자 진행, 학생 참여, AI 출제, CSV) |
| `store.js` | 데이터 저장소(브라우저 저장). 나중에 서버를 붙일 때 여기만 바꿉니다 |
| `make-password-hash.html` | 관리자 비밀번호 값을 만드는 도구 |
| `assets/logo.webp` | 강좌 로고(헤더·팝업·브라우저 탭 아이콘). 경로는 `config.js`의 `brand.logo` |
| `assets/instructor.jpg` | 교수자 사진(직접 넣으세요. 없으면 꽃 아이콘이 표시됩니다) |

## 2. 내용 고치기

**방법 A — `config.js`를 직접 편집** (가장 확실한 방법)
메모장 등으로 열어 문구만 바꾸고 저장한 뒤 브라우저를 새로고침합니다. `※ 예시`라고 적힌 값(수업 장소, 참고 영상·제출 링크, 통계 숫자, 연락처 등)은 실제 정보로 바꿔야 합니다.
- 첫 수업 날짜는 `schedule.start` 하나만 바꾸면 15주 전체 날짜·달력·과제 마감일이 함께 바뀝니다.

**방법 B — 관리자 화면에서 고치기** (아래 3번)

## 3. 관리자 모드

1. 화면 오른쪽 위 **🔒** 버튼 → 비밀번호 입력
2. 탭 구성
   - **사이트 편집**: 항목을 골라 화면에서 바로 수정 → *저장하고 적용*
   - **수강생 명단**: `학번, 이름`을 한 줄에 하나씩(엑셀에서 복사·붙여넣기 가능) 등록. "명단에 있는 학생만 로그인 허용"을 켤 수 있습니다
   - **공지**: 제목·내용을 올리면 첫 화면의 *공지사항* 섹션에 표시(고정 가능)
   - **출석 / 과제 / 회원 가입**: 현황을 보고 **엑셀(CSV)** 로 내려받기. 과제 파일은 [내려받기]로 하나씩 받습니다
   - **설정·백업**: 설정 파일(.json) 저장·불러오기, 배포용 `config.js` 내려받기, 비밀번호 변경, 수정본 초기화
3. CSV는 엑셀에서 더블클릭하면 한글이 깨지지 않고 열립니다.

**비밀번호:** 담당자가 정한 값이며 이 문서에는 적지 않았습니다. 설정·백업 탭에서 언제든 바꿀 수 있습니다.
비밀번호는 코드에 원문이 아니라 `config.js`의 `admin`(salt + 해시값)으로만 들어 있습니다. 다만 짧거나 흔한 비밀번호는 해시값만으로도 추측될 수 있으니, 공개 저장소에 올린다면 길고 예측하기 어려운 값을 권장합니다. 비밀번호를 잊었다면 `make-password-hash.html`을 열어 새 값을 만들고 `config.js`의 `admin` 부분을 교체하면 됩니다.

## 3-1. 라이브 퀴즈 (Kahoot·Socrative 방식)

화면 아래쪽 ‘강의실’ 다음에 있는 **라이브 퀴즈** 섹션입니다.

**교수자 (관리자 로그인 🔓 후)**
1. 문제를 만들거나 고칩니다(보기 4개, 정답 선택, 제한 시간, 해설). 자동 저장됩니다. 처음에는 예시 문제 3개가 들어 있습니다.
2. **AI로 문제 만들기**: 주제·수업 내용을 적고 문항 수·난이도를 고르면 문제가 추가됩니다. 추가된 문제는 꼭 직접 확인하세요.
   - *API 키 방식*: 본인의 API 키를 입력합니다. 키는 저장하지 않고(새로고침·잠금 시 사라짐) 입력한 AI 서비스로만 전송됩니다. 키가 브라우저에 노출되는 방식이므로 **공용 PC에서는 쓰지 말고**, 발급 시 사용 한도를 걸어 두세요.
   - *키 없이 쓰기*: [프롬프트 복사] → 다른 AI에 붙여넣기 → 결과 JSON을 [가져오기]에 붙여넣기.
   - 모델·요청 주소는 `config.js`의 `quiz.ai`에서 바꿉니다. 키를 숨기는 프록시 서버 주소를 `endpoint`에 넣으면 키 입력 없이도 쓸 수 있습니다.
3. **방 열기** → 화면에 PIN과 QR이 뜹니다. 학생이 모이면 **퀴즈 시작**.
4. 문제마다 학생이 모두 답하거나 시간이 끝나면 자동으로 정답·선택 분포가 나오고, [순위 보기] → [다음 문제]로 진행합니다. 점수는 정답이면 최대 1000점(빨리 맞힐수록 높음)입니다.
5. 끝나면 **학생별 결과 CSV**(순위·점수·문항별 선택/정답/시간)와 **문항별 통계 CSV**(정답률·보기별 선택 수)를 내려받습니다. 결과는 최근 5회분이 저장되어 방을 닫은 뒤에도 다시 받을 수 있습니다.

**학생**: 교수자 화면의 QR을 휴대폰 카메라로 촬영하면 PIN이 입력된 상태로 이 페이지가 열립니다(또는 PIN 6자리 직접 입력) → 닉네임 입력 → 입장 → 문제가 뜨면 보기를 누릅니다. 로그인했다면 학번이 결과 CSV에 함께 기록됩니다.

**알아둘 점**
- 연결은 PeerJS(WebRTC)를 씁니다. **인터넷이 필요**하고, 교수자 화면과 학생 화면 모두 처음에 라이브러리(cdnjs)와 PeerJS 연결 서버(0.peerjs.com)에 접속합니다. 학교·기관 네트워크가 WebRTC를 막으면 연결되지 않을 수 있으니 수업 전에 한 번 시험해 보세요.
- 학생이 QR로 들어오려면 사이트가 **인터넷에 배포된 주소**여야 합니다. `index.html`을 파일로 열어서는 학생 휴대폰이 접속할 수 없습니다.
- 퀴즈 방은 교수자 브라우저 탭이 켜져 있는 동안만 유지됩니다. 퀴즈 도중 탭을 닫거나 새로고침하면 방이 사라집니다. 동시 접속 한도는 `config.js`의 `quiz.maxPlayers`(기본 80)입니다.
- 정답은 문제가 끝난 뒤에야 학생에게 전달되지만, 학생 닉네임은 본인 입력이라 본인 확인용이 아닙니다.

## 4. 꼭 알아야 할 한계 (서버가 없는 사이트입니다)

- **모든 데이터는 "각자의 브라우저"에만 저장됩니다.** 학생 A의 투표·회원 가입 정보·출석·제출 파일은 학생 A의 브라우저에 남고, 교수자 화면에서는 *교수자 브라우저에 쌓인 것만* 보입니다. 즉 여러 학생의 응답을 한곳에 모으려면 별도 서버(또는 구글 시트·Firebase 같은 서비스) 연결이 필요합니다. 현재는 화면과 흐름을 갖춘 시범 형태입니다.
- **관리자 잠금은 보안 장치가 아니라 실수 방지용 문입니다.** 파일을 직접 열어 보는 사람까지 막지 못합니다. 학생 로그인(학번+이름)도 본인 확인이 아니라 식별용입니다. 중요한 성적·개인정보는 이 방식으로 모으지 마세요.
- 관리자 화면에서 고친 내용은 **그 브라우저에만** 적용됩니다. 모든 방문자에게 반영하려면 *설정·백업 → config.js 내려받기*로 만든 파일로 배포 파일의 `config.js`를 교체하세요. 명단·공지도 같은 방법으로 배포됩니다.

## 5. 배포하기

배포할 파일: `index.html`, `config.js`, `styles.css`, `app.js`, `participate.js`, `admin.js`, `quiz.js`, `sha256.js`, `store.js`, `assets/`(사진)
(`README.md`, `make-password-hash.html`은 올리지 않아도 됩니다.)

| 방법 | 순서 |
| --- | --- |
| **Netlify Drop** (가장 쉬움) | app.netlify.com/drop 에 폴더를 끌어다 놓기 → 주소 발급 |
| **GitHub Pages** | 저장소에 파일 업로드 → Settings → Pages → 브랜치 선택 → `https://계정.github.io/저장소/` |
| **학교·기관 서버 / 웹호스팅** | 위 파일을 웹 폴더에 업로드(FTP 등). 별도 설정 불필요 |

배포 후 확인: 주소로 접속 → 첫 방문 폭죽·팝업 → 메뉴 이동 → 휴대폰에서도 열어 보기.

## 6. 문제 해결

- **화면이 이상하거나 비어 있을 때:** 주소 끝에 `?safe=1`을 붙여 열면 관리자 수정본을 무시하고 `config.js` 원본으로 표시됩니다. 이후 관리자 화면에서 *설정·백업 → 모든 수정본 지우기*.
- **환영 폭죽·팝업을 다시 보고 싶을 때:** 주소 끝에 `?welcome=1`.
- **출석 체크를 시험해 보고 싶을 때:** `config.js`의 `classroom.attendance.enforceTime`을 `false`로(시험 후 `true`로 되돌리기).
- **카카오톡 등 앱 내 브라우저에서 파일 제출·다운로드가 안 될 때:** 크롬·사파리 같은 기본 브라우저로 열어 주세요.
